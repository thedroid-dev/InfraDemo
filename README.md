# 🖥️ InfraDemo

InfraDemo es un proyecto de demostración de infraestructura para servidores Minecraft, mostrando cómo usar Docker y CI/CD.

---

## 🚀 Características
- Configuración de contenedores con Docker Compose  
- Ejemplo de pipeline CI/CD  
- Scripts de backup y monitoreo  
- Seguridad básica y permisos  

---

## 📦 Instalación
1. Instala Docker y Docker Compose.  
2. Clona este repositorio.  
3. Ejecuta `docker-compose up -d`.

## 🚀 Explicación
- **docker-compose.yml** → define servicios básicos (ejemplo: servidor Minecraft, base de datos, proxy).  
- **ci-pipeline.yml** → ejemplo de pipeline para integración y despliegue continuo.  
- **backup.sh** → script para generar copias de seguridad automáticas.  
- **monitor.sh** → script para monitorear recursos del servidor (CPU, RAM, TPS).  
- **deploy.sh** → script para despliegue rápido de actualizaciones.  
- **.github/workflows/** → pipeline CI/CD con GitHub Actions.  
- **README.md** → documentación clara y profesional.  
- **LICENSE** → licencia abierta (ej. MIT).
